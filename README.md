# Trouve Ton Artisan
Ceci est une application web pour but d'exercice, trouve_ton_artisan est un site web qui répertorie des artisans dans 4 catégories :
1. Bâtiment
2. Services
3. Fabrication
4. Alimentation

## Fonctionnement
trouve_ton_artisan est une application [react.js](https://fr.react.dev/) sur le port `:3000`. Pour plus d'information sur son l'ancement voire la [fiche de démarage de react](./frontend/README_REACT_APP.md).
